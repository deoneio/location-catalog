# Agent Guidelines

The comprehensive context, guidelines, and execution rules for AI Agents working on this project (ShareLoc) are located in:

**`.agent/AGENTS.md`**

Please refer to that file before beginning any tasks.

## Critical Rule
- **NEVER commit directly to `main` or `develop` branches.** Always create a dedicated branch (e.g. `feature/*`, `fix/*`, `docs/*`) and submit changes via Pull Request.
